What testing found — two bugs that silently disabled the judge

Bug 1 · worked around

Default judge model returns 404

The code defaulted to claude-3-5-sonnet-latest, which this account cannot access (404 not_found_error). Every judge call failed. Pointed the judge at an available model via SDR_MODEL=claude-sonnet-5.

Bug 2 · fixed in code

Text extraction crashed on models with extended thinking

llm.py read resp.content[0].text, assuming the first block is text. Modern models emit a ThinkingBlock first, so every call raised 'ThinkingBlock' object has no attribute 'text'. The exception was swallowed and the judge fell back to a dev-mode pass — so a "real key" run scored identical to mock. Fixed to select the first actual text block.

Impact: before the fix, the hybrid design's entire semantic layer was a no-op against any current model, while still reporting backend=anthropic. This is exactly the class of silent failure the project is built to prevent — caught here by testing the loop end-to-end instead of trusting the label.
